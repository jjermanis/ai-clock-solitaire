# ai-clock-solitaire
Playing Clock Solitaire


## Overview
The classic version of the solitaire game called Clock


## Description
This is a standard Clock Solitaire game. The game is shaped like a clock. There are 12 stacks of four cards each, faced down. The 13th stack is in the center. The game starts by turning over the top card in the center. You place that card to the location based on the value of that card. An Ace is 1 o'clock. A 2 is 2 o'clock, a 3 is 3 o'clock, and so on. The Jack is 11 o'clock, and the Queen is 12 o'clock. The King is the center. When you turn over a card, click and drag it to the expected location. When moved, the card moves over and a card from that stack is turned over. You win if all of the cards are turned over. If all four kings turned over first, you lose.


## Details
This game is pure probability - no strategy or tactics are involved. You have a 1 in 13 chance of winning a game.

This was (I believe) the very first game of solitaire I learned to play. I was very young.
